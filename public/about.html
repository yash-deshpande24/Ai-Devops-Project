🚀 Smart AI DevOps Platform

Created by Yash Deshpande

This project is an AI-powered DevOps Monitoring Dashboard that helps track system performance, detect failures, and simulate real-world cloud infrastructure behavior.

It integrates Artificial Intelligence concepts with Cloud and DevOps tools to automate monitoring, improve system reliability, and optimize performance.

🛠️ Technologies Used

  • Node.js (Backend API)
  • Docker (Containerization)
  • AWS (Cloud Deployment)
  • JavaScript / HTML / CSS
  • Basic AI/ML Concepts
